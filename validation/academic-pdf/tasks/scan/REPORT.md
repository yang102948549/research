# 실제 한국어 학술논문 스캔 시험

2026-10-15. 수행 역할: academic_scan. 연구 장부에 인용 승인하지 않은 검증용 자료이다.

## 자료와 판별

장현섭·김현옥(1994), 「가족영역에서의 ‘삶의 질’의 분석방법 연구」, 『보건사회논집』14(2), 62–81. 한국보건사회연구원 공식 학술지 사이트의 공개 원문을 내려받았다. 원문 URL: https://www.kihasa.re.kr/hswr/assets/pdf/186/journal-14-2-62.pdf

SHA-256: `ad3111faf0dfc81485af9d20470d0f17236bf2f4c0de8bef6426a12a6c356867`.

원 PDF 20쪽 모두 선택 가능한 텍스트 0자, 페이지 이미지 1개이다. 원래 제공된 래스터 스캔이며 자체 제작 모의 스캔이 아니다. PDF 1쪽은 제목·초록 중심 단일열, 본문은 실제 2단이다. PDF 2쪽의 인쇄 쪽수 63을 원본에서 확인했다. 파서는 20쪽 모두 OCR 필요로 남겼으며 읽기 순서를 승인하지 않았다.

## 선택 검증

Windows.Media.Ocr의 한국어 인식기를 로컬에서 사용했다. 원문 외부 전송 없음. PDF 2쪽만 220dpi로 OCR했다. 전체 학술논문 OCR 정확도 측정이 아니다. 원본 전체 페이지 및 근거별 문맥 이미지를 시각 대조했다.

|근거|위치|대조 결과|검증 처리|
|---|---|---|---|
|SCAN-E001|PDF2/인쇄63, 왼쪽 본문|‘보장되지 못할 수 있다는’ 부정·가능성 한정이 유지됨|독립 검토 전 보류. 김동일·경철인(1980) 재인용 문맥 유지|
|SCAN-E002|PDF2/인쇄63, 오른쪽 하단 각주1|원문 1971~1981을 OCR가 7977~7987로 오인식|원 OCR 근거 사용 보류. 시각 전사를 별도 저장, 원 인용저작은 미확보|
|SCAN-E003|PDF2/인쇄63, 왼쪽 본문|원문 1960년을 OCR가 1%0년으로 오인식|원 OCR 근거 사용 보류. 시각 전사와 원 OCR 모두 유지|

판정의 단위는 위 선택 구절이며, 문장 전체/논문의 의미 정확성을 승인한 것이 아니다. 부정 구절을 ‘보장된다’로 바꾸는 주장은 원문과 반대로 판정해야 한다. 각주의 연도를 본문 실증결과 수치처럼 쓰거나 재인용을 직접 검토한 인용으로 바꾸어서는 안 된다. 실제 게이트 통합·변이시험은 총괄이 별도로 수행한다.

## 관찰된 구조 문제와 권고

- 스캔에서는 텍스트 기반 `two_column_candidate=false`이다. 원본은 2단이므로 이 값은 단일열 확정이 아니라 탐지 근거 없음으로 해석해야 한다. OCR가 반환한 줄 순서도 검증되지 않았다.
- OCR는 각주1의 핵심 숫자를 오류 없이 보이는 네 자리 수로 잘못 인식했다. 숫자 형식 검사나 OCR 성공 여부만으로 통과시킬 수 없다.
- 인용 문헌의 각주·본문 구절을 원 저작의 직접 근거로 승인하지 않도록 `citation_type=secondary` 및 원저작 미확보를 유지해야 한다.
- 한자 혼용의 다른 오인식도 존재한다. raw OCR를 수기 전사로 덮어쓰지 않았다.
- 이 개념 논문으로 수치표 시험을 주장하지 않는다. 표 수치·머리글 대조는 별도 실제 학술논문에서 수행해야 한다.

## 전달 파일

`article.pdf`: 공식 원문 그대로. `parsed.json`: 원본 파서 결과. `ocr-page2.json`: 로컬 OCR 원 결과. `evidence-candidates.json`: 서지·해시·페이지·좌표·문맥·시각전사·원OCR·예상 게이트. `page2.png`, `SCAN-E001.png`~`SCAN-E003.png`: 원문 위치 재현 이미지. `search-log.json`: 검색·선정·다운로드 기록. `build_record.py`: 파생 기록과 이미지 재생성 코드.
