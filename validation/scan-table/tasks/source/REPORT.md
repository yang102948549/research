# 실제 스캔 표 수집·전사 작업

이가옥·서미경·김정석(1994), 「취약계층 노인의 부양실태 비교분석」, 『보건사회논집』14(2), 3–19. 공식 발행처 PDF를 변환하지 않고 보존했다. 17쪽 모두 추출 텍스트 0자, 각 1개 래스터 이미지다. 실제 내려받은 스캔이며 디지털 문서를 모의 스캔으로 만든 자료가 아니다.

시험 표는 PDF 5쪽 / 인쇄 7쪽의 표2다. 3개 패널 행 × 2개 패널 열, 패널별 3개 수치 열 × 7개 자료 행으로 총126셀을 전사했다. 패널 제목은3개 열을 묶고, 연령·성·지역은각2행을 묶는다. 원본 표에 모든 세로선이 그어진 것은 아니므로 병합은 화면상 의미적 범위의 수동 전사이며 PDF의 원래 셀 객체를 복원한 것이 아니다.

표의 기본 단위는%지만 `계(명)`은100.00이라는 백분율과 괄호의 인원수를 함께 담는다. 이를 단일 단위로 평탄화하면 안 된다. 주석1은승수부여 때문에 총계가 일치하지 않을 수 있음을 명시한다. 주석2·3·6·7은무응답·대리응답 제외,4·5·7은해당 패널의 모집단 범위,8은유의수준 표시다. 원문에서 별표는패널 및 행 집단마다 다르므로 전체 행에 동일하게 전파하지 않는다.

로컬 Windows 한국어 OCR 원문은 `ocr-page5.json/txt`에 별도 보존했다. 실제 오류에는 `49.54→4954`, `23.50→2350`, `10.22→1022`, `548→618`, `%→90`, `10명→1()명`, `73.96→73.%` 등이 있다. 표를 읽은 OCR의 전체 줄 순서는 패널을 교차하므로 텍스트 순서만으로 수치를 행·열에 배정할 수 없다.

원본에도 검토가 필요한 값이 있다. 주관적 경제평가 전체 행의 첫 값은77.68로 읽히며 두번째20.32와 합이98.00이다. 임의로79.68로 교정하지 않았으며, 승수 주석으로 이 불일치까지 자동 정당화하지도 않았다. 이 셀의 해석은보류한다.

수동 전사는독립 검토 전 상태다. `table-transcription.json`의좌표는PDF point 단위의 수동 경계이며 셀 그림을 재렌더하여 확인해야 한다. 표 전체·머리글·주석 렌더도 제공했다. 최종 근거 승인은총괄과 독립 검토자에게 넘긴다.
