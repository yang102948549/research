# 역할 카드

루트 AGENTS.md의 표준 단계(기준 분석 · 도전 분석 → 통합 → 독립 검토 → 수정)를 문헌연구에서 수행할 때 하위 작업자에게 그대로 전달하는 카드다. 카드는 주제와 무관하며 연구별 내용은 연구 폴더의 AGENTS.md와 배정 메시지에 둔다. 동시 실행 수·게이트·파일 소유권은 루트 AGENTS.md가, 인계 JSON과 산출물 형식은 [orchestration.md](../references/orchestration.md)가 정하며 카드에서 다시 정하지 않는다.

| 카드 | 표준 단계 | 쓰는 곳 | 비고 |
|---|---|---|---|
| [source-acquirer.md](source-acquirer.md) | 준비(원문 확보) | tasks/<작업ID>/ | 후보 발굴·원문 확보·서지 대조 |
| [source-analyst.md](source-analyst.md) | 기준 분석 | tasks/<작업ID>/ | 원전 입장의 충실한 재구성 |
| [objection-analyst.md](objection-analyst.md) | 도전 분석 | tasks/<작업ID>/ | 가장 강한 이의 탐색 |
| [independent-reviewer.md](independent-reviewer.md) | 독립 검토 | tasks/<작업ID>/ | 새 컨텍스트, 작성 불참 |
| [drafter.md](drafter.md) | 작성 | tasks/<작업ID>/ | 승인된 개요 안의 초안 |

총괄은 카드가 아니라 루트 AGENTS.md를 따른다. 장부, 최신 개요, 통합 원고, 공통 문헌목록은 총괄만 수정한다. HWPX 읽기·편집은 역할이 아니라 [hwpx-document](../../hwpx-document/SKILL.md) 스킬이며 어느 역할이든 필요할 때 읽는다.
