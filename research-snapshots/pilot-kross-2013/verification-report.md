# 검증 보고서

투고 전 검토용 원고. 자동 투고하지 않음.

장부 버전: 16

원고 게이트: 통과. 각 문단은 검토한 주장 문구에 연결됨.

검증 범위: 에이전트의 원문·맥락 대조, 파일 해시, ID 연결, HWPX XML/패키지 및 내용 재추출.

한계: 같은 모델 역할 분리는 완전한 독립성이나 무환각을 보장하지 않음. 사람의 원문 검토와 전체 스키마 검증은 미완료. HWPX 실제 열기·렌더링 시각 검증은 완료(에이전트, 한글 2022, 전체 1쪽).

## 주장별 한계

- C001: 원문에 보고된 자료 수집 절차이며 무작위 처치 실험을 뜻하지 않는다.
- C002: 해당 표본과 분석에서의 예측 관계이며 모든 이용자에게 동일한 인과 효과가 있다는 주장이 아니다.
- C003: 종단 분석의 시간적 정보와 확정적인 인과관계를 구분해야 한다.
- C004: 청년 중심의 단일 연구를 다른 연령층이나 모든 소셜네트워크로 확대하지 않는다.

KCI 실연결·한국어 2단 PDF·OCR·표 수치 추출은 이 XML 시험으로 검증되지 않음.

## 후속 실제 렌더링 검증

한글 2022에서 수정본을 열어 PDF로 저장하고 전체 1쪽을 이미지로 대조했다. 한글·본문 인용·참고문헌·DOI의 표시와 잘림·겹침 없음을 확인했다. 영어 참고문헌의 과도한 단어 간격은 왼쪽 정렬로 수정했다. 렌더 PDF와 HWPX 재추출문은 공백 정규화 후 정확히 일치한다. 검토 해시와 범위는 `validation/hwpx/visual-review.json`에 기록했다.

한국어 PDF/OCR은 별도 수능 문제지 및 모의 스캔 시험: 선택 문구 8/10 일치, 부정 표현·상자 문구 실패, 달력 머리글 실패. 모든 OCR 결과는 근거 승인 전 검토 대기다. 실제 학술논문·종이 스캔은 미검증. KCI는 실키 미설정이다.
