# 실제 한국어 학술논문 PDF·스캔 검증

시험일: 2026-10-15. 사용자 요청에 따른 파싱·원문 추적·게이트 검증이며 새로운 연구질문이나 원고 집필의 승인이 아니다. 두 문헌의 선택 영역만 검토했다.

원문은 공식 제공 파일 그대로 보관했고 자체 래스터화 PDF로 스캔을 대신하지 않았다. 다운로드·검색기록·원본 SHA는 각 tasks 하위 기록에 있다. 학술자료 전체를 검색한 체계적 문헌고찰이 아니다.

수집자가 아닌 에이전트가 정답 기록을 읽지 않고 원문 전체 쪽과 확대 영역을 대조했다. 올바른 주장7건 통과, 잘못된 주장7건 수정. 이는 같은 모델의 역할 분리이며 완전한 독립성이나 무환각을 보장하지 않는다. 스캔 논문이 인용한 원 저작의 역사적 사실을 별도로 검증한 것은 아니다.

## 발견 문제와 수정

1. **PDF 게이트의 위치 검사 누락:** 수정 전 설치본에서 존재하지 않는9999쪽·가짜 구절·좌표 없는 근거가 evidence_errors를 통과하는 것을 실제 파일로 재현했다. 실제 페이지 범위, 유한 좌표, 원본에서 재렌더한 이미지와 저장 검토 이미지의 픽셀·SHA 대응, native 구절 일치, 독립 검토 및 내용 해시를 추가했다. `baseline-gate.json`은 수정 전 재현 기록이다.
2. **전폭 표의 잘못된 읽기 순서 제안:** 실제 PDF4쪽에서 표 일부가 본문 앞으로, 나머지가 뒤로 분리됐다. 본문 중간을 가로지르는 블록이 있으면 proposal을 null로 하고 수동 검토 사유를 남긴다. 원본 블록·좌표는 유지한다.
3. **스캔의 열 수 오해:** 텍스트 없는 스캔은 two_column_candidate=false라도 실제 단일열이 아니다. layout_status=unknown_no_native_text를 추가했다.
4. **인쇄 쪽수 추론:** 독립 검토 초안이 첫쪽 서지의 시작값291을 인쇄 쪽수로 기록했다. 원본을 재대조해 printed_page=null, bibliographic_start_page=291로 정정했다. 검토 해시는 정정 후 기록으로 갱신했다.
5. **핸드오프 형식 편차:** 실제 작업 결과가 자유 형식 판정·output_paths·한글 별칭을 사용했다. 원본을 유지하고 총괄이 ID·파일·현재 장부·배정 입력을 재대조한 정규화 기록을 작성했다. 장부는 잘못된 형식을 직접 수용하지 않는다.

6. **PDF 형식 우회:** 독립 코드 검토가 실제 PDF를 HTML 위치로 표시하면 PDF 검사가 생략되는 경로를 재현했다. 실제 원문 바이트의 PDF 시그니처와 위치 유형을 연결해 수정했다. 확장자를 .bin으로 바꾼 PDF도 우회하지 못한다.

10개 구조 변이(없는 페이지, 범위 밖 좌표, 표 수치 변경, 표 문맥 누락, raw OCR 승인 시도, 자기검토, 인쇄 쪽수 변경, 검토 이미지 누락, PDF의 HTML 위장, 확장자를 바꾼 PDF의 HTML 위장)를 모두 차단했다. 별도 회귀시험은 검토 이미지 바꿔치기도 거부한다. 구조 검사는 문장의 의미를 판단하지 않으며, 의미 오류 거부는 실제 독립 검토 결과에 근거한다.

## 범위와 재현

근거7개·독립 판정14개·구조 변이10개를 `gate-results.json`과 `ledger.json`에 보관했다. 원 OCR와 수정 전사, 원문 PDF 순번과 인쇄 쪽수, 확대 이미지, 해시, 원본/정규화 핸드오프를 분리했다. 질문·개요 승인은 생성하지 않았으며 이 시험으로 연구 원고 완료를 선언하지 않는다.

두 문헌 전체의 의미·모든 표/각주를 승인한 시험이 아니다. 스캔은 PDF2쪽만 OCR했다. 수치표는 텍스트 PDF에서 검증했고, 스캔 표의 복잡한 병합 셀 복원은 미검증이다. KCI 실연결은 키 미설정으로 여전히 미실행이다. 원문 파생 파일은 연구 검증 폴더에 보관하고 설치 스킬에 포함하지 않는다.

최종 회귀시험: 61개 통과. 스킬 형식 검사와 설치 해시 검사 통과 여부는 build-status.json/최종 실행 기록에 보존한다.
