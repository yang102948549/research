# 실제 한국어 2단 학술논문 시험

시험일: 2026-10-15. 자료: 유재우·구본진·장덕현(2015), 「지역대표도서관 입지 선정에 관한 연구: 부산광역시를 중심으로」, 한국문헌정보학회지 49(3), 291–309. DOI 10.4275/KSLIS.2015.49.3.291.

공식 학회 AccessON PDF: https://www.accesson.kr/kslis/assets/pdf/9356/journal-49-3-291.pdf

원문 첫 페이지를 렌더하여 제목·저자·연도·권호·DOI를 대조했다. 본문 2쪽(인쇄 292) 및 4쪽(인쇄 294)을 전체 렌더하여 실제 2단 편집을 확인했다. PDF는 빈 마지막 쪽을 포함한 20쪽이다. 첫 쪽의 논문 시작 쪽은 서지상 291이지만 눈에 보이는 인쇄 페이지 라벨은 없어 위치 필드에는 null을 보존했다.

원본 전체 쪽과 선택 좌표 확대 PNG를 직접 읽었다. 원문·추출문·좌표·원본 해시·음성 대조군 주장을 evidence-candidates.json에 보존했다. 이 판정은 추출 정확성 표본 검사이며, 독립 의미 검증/장부 승인을 자동 부여하지 않는다. 각주 표본은 첫 쪽 연구 출처 각주이며 긴 논증 각주나 다단 연결 각주를 시험했다는 뜻이 아니다.

## 발견된 문제

기존 parser의 p4 proposed_block_order는 왼쪽으로 분류된 표의 ‘추가 계획 면적’과 ‘합계’ 셀을 먼저 놓고, 전폭 표 머리글·행·표 제목을 본문 양쪽 열 뒤로 옮긴다. 즉 표 한 개를 분해하여 문맥과 위치 순서를 잘못 제안한다. native block 순서 역시 표 제목이 표 행 뒤에 나와 완전한 읽기 순서가 아니다. 현재 reading_order_verified=false / needs_review를 유지하므로 자동 승인된 오류는 아니지만, mixed-layout에서는 순서 제안을 보류하거나 구역 단위로 분할해야 한다. 실제 p4에 대해 이 동작을 회귀시험으로 고정할 것을 권고한다.

p4 그림 1의 이미지 텍스트는 OCR 요청 영역으로 정확히 분리되며, 표 1은 selectable text이므로 표 수치 확인에 그림 OCR이 필요하지 않았다. 페이지 전체 ocr_required를 표 수치 검증 완료와 혼동하면 안 된다. 현재 시험은 페이지 전체 완전 파싱 판정이 아니다.

## 한계 및 다음 전달

독립 검증자는 4개 원문 주장과 반대/수치변조 주장 각각을 대조한다. source SHA와 위치를 바꾸는 대조군은 코드 게이트에서 차단되는지 총괄이 확인한다. 자료 1편·네 위치를 넘어선 일반 성능 수치를 주장하지 않는다. PDF 전체 저작물은 공개 원문 테스트 기록으로만 보관하며 본문을 보고서에 대량 재게시하지 않는다.
