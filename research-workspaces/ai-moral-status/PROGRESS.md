# 연구 진행 기록 — 2026-10-15

연구질문: 현재 생성형 AI·LLM의 도덕적 지위를 인정할 근거는 무엇인가?

사용자의 범위 수정에 따라 잠정적 보호 정책을 제외했다. 한국어·영어의 비판적 문헌연구로 2022년 이후 LLM 관련 문헌을 중심에 두고 이전 이론을 비교한다. 분량·투고처·기한은 미정이다.

총괄 아래 국내·국제·이론/반론 작업자 3명이 조사했다. 신규 후보 14편(국내5/국제4/이론5)을 후보 목록에 통합했으며 예비 타당성 확인용 2편은 별도 장부에 유지한다. 원문 검증이나 최종 채택 완료 건수가 아니다. 검색식·접근 범위·한계는 작업자별 JSON에 보존했다. KCI API를 이용한 본격 수집은 하지 않았고 이번 연구 후보 검색은 공개 웹·출판사·KCI 서지 페이지를 사용했다.

국외 후보 중 Chalmers 저자 에세이와 Shardlow·Przybyła PLOS 논문의 HTML 바이트를 확보하고 SHA-256 및 초기 문단 추출을 저장했다. 다른 2개 출판사 요청은 충분한 본문을 확보하지 못해 실패로 기록했다. HTML 추출에는 본문 외 요소가 섞일 수 있어 원문 대조 전 근거로 승인하지 않는다. Chalmers의 내려받은 에세이와 관련 arXiv 판본도 별개로 취급한다. 국내 5편은 서지·초록 확인 단계이고 원문 미확보다.

분석은 도덕적 지위의 규범적 인정 기준과 현재 모델이 그 기준을 충족한다는 사실적 근거를 구분한다. 의식/감응능력·이익, 행위자성과 피행위자성, 관계적 인정, 의인화 비판을 비교하되 결론을 미리 정하지 않는다. 의식 논문만으로 도덕적 지위를 확정하지 않는다.

KCI 논문검색은 생성형 인공지능 쿼리의 10/20건 크기·첫 2페이지·마지막/범위밖 응답 표본 통과. 참고문헌 API는 식별자 및 경계 응답 문제로 보류한다. 연구 수집에는 articleSearch 10/20건 또는 공개 원문 경로만 사용한다.

다음 작업: 국내 핵심 논문 원문 확보 → 확보 HTML 본문/메타데이터 대조 → 출처·위치가 있는 근거 카드 → 별도 작업자의 독립 의미 검토 → 상세 개요 제안. 개요 승인은 아직 받지 않았고 원고는 작성하지 않았다.


## 원문 확보 및 첫 근거 검토 완료

국내 KR002–KR005 전체 PDF 4편 확보, KR001은 1쪽 미리보기만 확보했다. 전체 원문은 기존 HTML 2편과 합쳐 6편이다. 국내 PDF는 추출·쪽수·첫 페이지 서지 확인 단계이며 근거 의미 검증은 아직 미완료다.

국외 HTML에서 E001–E004 근거 카드와 대응 C001–C004를 등록했다. 작성과 분리된 검토자가 원문 인용·위치·맥락을 대조하여 네 건을 제한된 원저자 견해로 통과 판정했다. 원문 전체 파싱 승인이 아니라 선택 문단만 검증했다. 전체 추출에는 메뉴/푸터와 일부 절 제목 누락이 남아 hold이다. Chalmers의 실제 Boston Review 취득 URL, 발행일과 페이지 수정일 차이, arXiv와의 판본 구분을 기록했다.

다음 단계는 국내 PDF의 핵심 구절 시각·문맥 검증과 규범적 인정 기준 근거 보강이다. 현재 네 카드는 의식 논증의 방법과 한계를 설명하므로 도덕적 지위 인정의 충분근거로 일반화하지 않는다. 상세 개요·원고 작성은 아직 수행하지 않았다.
