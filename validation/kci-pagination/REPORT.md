## 코드 검증

- 회귀시험 78개 통과(기존 64개 + 페이지 처리 14개).
- 논문 ID 기반 페이지 내/페이지 간 중복 차단, total 초과 차단, 요청 크기와 응답 크기 불일치 시 중단.
- 페이지 번호의 소수·불리언 입력 차단. 정수 문자열은 정규화.
- 참고문헌은 outputData의 article-id를 보존하고 내용 지문과 조합. 논문별 고유 식별자와 같은 강도의 검증은 아님.
- 구형 체크포인트는 새 검증 없이 complete로 신뢰하지 않고 명시적으로 거절. 기존 파일은 보존하고 새 경로로 재수집 필요.
- 독립 코드 검토에서 마지막 페이지와 두 번째 페이지의 중복 누락을 발견하여 수정. reviewer/followup.json과 resolution.json에 기록.

## 실서버 실행

복구 저장소 루트에서:

```powershell
& '.\evidence-paper-workflow\scripts\kci_pagination_probe.ps1' -Title '인공지능'
```

키는 숨김 입력. 기존 프로세스 환경에 키가 있으면 재사용하고 종료 시 원래 환경을 복구한다. 결과는 validation/kci-pagination/live-날짜-시각.json에 저장하며 원문 XML·키·요청 URL은 저장하지 않는다.

두 검색 API별 최대 7회, 총 최대 14회, 재시도 없음. 크기 1/10/20, 1·2페이지 연결, 첫 페이지 재조회, 마지막 및 다음 페이지를 검사한다. 초기 요청·인증 오류는 중단한다. 마지막/범위밖 페이지 오류는 해당 API를 미완료로 남기고 다른 API 검증을 계속한다. 1건 요청이 10건으로 대체되는 경우 진단으로 남기며 10/20건 경계 검증과 구분한다. 표본 검증이므로 중간 모든 페이지의 완전성을 보증하지 않는다. 정렬 동률·실시간 데이터 변동도 needs_review의 원인이 될 수 있다.

공식 명세: [논문검색](https://www.kci.go.kr/kciportal/po/openapi/openDataView.kci?datasetBean.dtstSeqNo=1), [참고문헌검색](https://www.kci.go.kr/kciportal/po/openapi/openDataView.kci?datasetBean.dtstSeqNo=2). 2026-10-15 확인.


## 실제 실행 결과: 2026-10-15 20:08 KST

live-20261015-200850-107.json 확인. 검색어 인공지능, articleSearch 총 19,106건. 1건 요청은 10건 반환했고 10건 요청의 식별자 순서 지문과 동일했다. 10·20건 요청은 각각 10·20건을 반환했고 첫 페이지 재조회 지문은 일치했다. 2페이지 지문은 1페이지와 다르다. 단, 지문 차이만으로 두 페이지의 중복 부재를 증명할 수 없다.

마지막 1,911페이지에서 network_error로 중단하여 referenceSearch는 미실행이다. 이전 보고서에는 앞부분의 집합 비교 판정이 저장되지 않았으므로 합집합 일치나 중복 부재를 소급하여 통과로 간주하지 않는다. HTTP 상태 기록이 없어 실패 원인은 미확정이다.

도구를 보완해 마지막 페이지 실패 전 부분 판정을 보존하고, 해당 API의 경계 검증은 미완료로 두면서 다른 API 시험을 계속한다. HTTP 오류는 상태 코드만 기록하며 키·URL·오류 본문은 출력하지 않는다. 합성 HTTP 500 시나리오 포함 78개 시험 통과. 재실행은 더 좁은 검색어 생성형 인공지능을 사용한다. 총 결과가 10건 이하면 페이지 검증에 불충분한 것으로 표시한다.
