# 한국어 PDF·로컬 OCR 검증

시험 자료는 사용자 로컬 `C:/Users/USER/Desktop/OneDrive/claude/PDF파싱/국어.pdf`(40쪽, 2026학년도 수능 국어 문제지)이다. **학술논문이 아니며, 실제 종이 스캔을 확보한 시험도 아니다.** 기존 텍스트 PDF와 그 1·11쪽을 200dpi로 래스터화한 통제된 모의 스캔을 시험했다. 저작권이 있는 원문과 파생 이미지·PDF는 로컬 검증 자료로만 보관하며 배포용 스킬 패키지에 포함하지 않는다.

## 실행과 판정

- PyMuPDF 원문 추출은 한국어 본문, PDF 순번, 블록 좌표와 원본 블록 순서를 보존했다. 1·11·18·19쪽에서 2단 후보를 탐지한다. 열 순서 제안은 검토 보조이며 확인 완료 상태가 아니다.
- `printed_page`를 임의로 채우지 않는다. 실제 18쪽은 상단에 `2`, 하단에 `18 / 20`이 있다. 두 표기를 구분해야 한다.
- 1·11쪽은 텍스트가 충분하여 OCR 요청이 없다. 실제 18쪽은 본문에 텍스트가 있어도 오른쪽 공지·블로그 이미지 두 영역의 텍스트가 없어 영역 OCR을 요청한다.
- 모의 스캔 1쪽은 이미지 전용이고, 2쪽은 스캔 이미지 위에 20자가 넘는 선택 가능한 시험 머리말을 넣었다. 둘 다 OCR 필요로 판정한다. 기존 `<20자` 조건만으로는 두 번째 사례를 놓쳤다.
- 설치된 `Windows.Media.Ocr` 한국어(`ko`)로 로컬 OCR을 실행했다. 클라우드 업로드·유료 API·추가 모델 다운로드 없음. 샌드박스에서는 WinRT 접근 거부가 발생하여 승인된 로컬 실행으로 검증했다. 접근 오류·언어 미설치·시간 초과를 성공으로 기록하지 않는다.
- 10개 고정 문구·수치 검사 중 **8개 일치, 2개 불일치**(공백만 무시). 완전한 OCR 정확도 지표가 아닌 선택 구절 점검이다.
- 실패 1: 부정 표현 `설명하지는 않는다`가 `설명하지= 鬱죠=다`로 오인식됐다. 실패 2: 상자 안 `단순 관점`이 질문 문장 OCR에서 누락됐다. 원문 대조 없이 이 구절을 주장 근거로 승인할 수 없다.
- 11쪽 각주 `봉고파출: 어사가 고을 원을 파면하고 관가의 창고를 잠금`은 일치했다. 최초 수기 정답의 `아사가` 오타는 확대 원본 이미지로 재확인해 `어사가`로 수정했다. OCR 결과 자체를 정답으로 채택하지 않았다.
- 실제 18쪽 래스터 공지의 `월 5권 이내, 14일간`, `09:00`, `18:00`, `3일간 재신청 불가`는 일치했다.
- 실제 19쪽 달력 표는 숫자 1–7과 좌→우 셀 위치를 보존했다. 그러나 요일 머리글 일부와 `정기 휴관`이 누락·오인식되었다. **표 전체 검증 실패**, 수기 전사와 독립 원본 검토가 필요하다. 일반 텍스트 OCR을 표 구조 복원으로 표시하지 않는다.

## 반영 사항

`parsing.py`: 이미지 영역 단위 OCR 필요 판정, 원본 블록ID·페이지좌표, 검증 전 2단 순서 제안, 미검증 읽기 상태.

`local_ocr.py` + `windows_ocr.ps1`: 한국어 명시, 실패 시 중단, 호출 시간·파일 크기·영역 수 제한, 요청된 영역만 처리, 단어 좌표를 원문 PDF 좌표로 복원, OCR은 항상 시각 검토 필요. Windows 엔진은 신뢰도 점수를 제공하지 않으며 이를 임의 생성하지 않는다.

`test_pdf_ocr.py`: 혼합 이미지·머리말, 정상 텍스트 선택적 제외, 좌표 변환, 시간 초과, 언어 미설치, 2단 후보 순서, 잘못된 페이지 번호 회귀시험 7개. 같은 높이의 양쪽 열이 하나의 추출 블록으로 합쳐지면 2단 후보를 탐지하지 못할 수 있으므로, 후보 미탐지를 단일 열 검증으로 해석하지 않는다.

## 남은 범위

실제 한국어 학술논문 2단 레이아웃, 촬영·기울어짐·저해상도·종이 잡음이 있는 실스캔, 복잡한 통계표·다중 병합 셀은 별도 자료로 시험해야 한다. 현재 결과는 해당 영역의 전면 통과를 의미하지 않는다. 원문에서 확인한 부정 표현·표 숫자를 별도 근거 카드로 작성하려면 사람이거나 독립 검토자가 원문 위치와 함께 재검토해야 한다.

재현: PDF 생성 전 PDF 스킬의 artifact marker를 실행한 뒤 `python run_validation.py <로컬 원문 경로>`를 사용한다. 원문이 없는 설치 환경에서는 실제 자료 시험은 실행되지 않는다. `finish_checks.py`는 저장된 결과와 확대 이미지 검토 기준으로 달력·정답 수정 기록을 추가한다.
