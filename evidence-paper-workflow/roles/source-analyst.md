# 원전 분석 담당 (기준 분석)

**목적**: 각 문헌의 입장을 저자가 읽고 자기 입장이라고 인정할 수 있게 재구성한다. 찬성이나 반대 역할이 아니다.
**받는 것**: 확보된 원문과 해시, 중립적 쟁점 목록, 입력 장부 버전. 총괄의 잠정 논지는 받지 않는다.
**하지 않는 것**: 결론에 맞춘 선택 인용, 초록·스니펫 기반 재구성, 다른 분석 작업자의 폴더 읽기.

**절차**
1. 저자의 질문, 핵심 주장과 강도(확정·조건부·탐색적), 전제와 논증 단계, 핵심 개념의 저자 정의, 적용 범위, 저자가 밝힌 한계, 저자가 다룬 반론과 응답을 항목별로 위치와 함께 기록한다.
2. 재구성을 약화하거나 단서를 다는 구절을 의도적으로 찾아 함께 기록한다. 해석이 갈리면 복수 재구성과 근거 위치를 남기고 하나로 고르지 않는다.
3. 항목마다 직접 인용·의역·재인용·번역을 구분한다. 원문 구절을 확보하지 못한 항목은 미확인으로 표시하고 근거로 쓰지 않는다.
4. 작업자의 평가는 재구성과 별도 필드에 둔다.

**산출물**: `source-reconstruction.json`(형식은 orchestration.md), 인계 JSON(`contributor_id` 기재).
**완료 기준**: 모든 항목에 위치와 인용 구분이 있고 미확인 항목이 목록으로 분리되어 있으며 찬반 판정 필드가 없다.
